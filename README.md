# Academia · Site modelo

Interface de site para o segmento fitness, com apresentação de planos, modalidades e estrutura da academia.

**[Abrir demonstração](https://jroberto7.github.io/Academia-Modelo/)** · [Conhecer meu trabalho](https://github.com/jroberto7)

## O que o projeto apresenta

- Página de apresentação com chamadas para ação.
- Comparação visual de planos e benefícios.
- Seções de modalidades, espaços e contato.
- Layout com recursos de adaptação para diferentes telas.

## Tecnologias

HTML, CSS e JavaScript, com estilos e scripts na pasta `assets`.

## Como visualizar

Clone ou baixe o repositório e abra `index.html` no navegador. Não há etapa de compilação.

## Sobre esta demonstração

Projeto de portfólio com marcas, textos, valores e depoimentos de exemplo. Botões comerciais são demonstrativos e não realizam contratação ou pagamento.
